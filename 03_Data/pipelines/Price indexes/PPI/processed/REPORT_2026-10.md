# PPI basket retrieval (October 2026 view)

- Question: Can BLS FD-ID final-demand and intermediate-demand component contributions be reproduced through Oct 2026?
- Sources: BLS PPI relative-importance workbooks (Dec 2025; 2026 tables), wp.series/pc.series lists, BLS API v2; archive: https://www.bls.gov/ppi/tables/final-demand-intermediate-demand-special-requests.htm
- FD terminal RI rows=33 (sum 99.999%); ID terminal RI rows=27; parent sums: ID61=100.000%; ID62=99.999%; ID63=100.000%.
- Weights use Dec 2025 RI repriced by component/aggregate NSA relatives; weights are normalized within each basket for the start of each horizon.
- Rates: 1m and 3m annualized use SA where available, otherwise NSA; 12m uses NSA. Contributions equal start-period weight times component rate.
- named_series.csv verifies each exact WPU commodity or PCU industry ID against official series lists; hospital inpatient and outpatient are separate rows.
- Uncertainty: any missing observations or codes stay blank and can widen reconciliation gaps; no neighboring series is substituted.
- Reconciliation gaps: see reconciliation_2026-10.csv (the September REPORT.md sentence on gaps is September-specific and omitted here).
